# Credits

## Code & content

INTAKE is an original project. All code, low-poly geometry, level layouts, UI, and synthesized audio in this repository were created for this project.

## Third-party

- **Three.js** — MIT License — <https://threejs.org/>  
  Vendored at `vendor/three.module.js`.

No external textures, models, music, or sound effects are used in this build. All audio is generated at runtime with the Web Audio API.

## Inspiration

- **Fury Foot** — visual reference for flat-shaded low-poly geometry, chunky silhouettes, and first-person presentation. No assets, code, maps, characters, HUD, or mechanics are copied.
- **Metro 2033** — tonal reference for underground survival horror, scarce resources, and suffocating atmosphere. No assets or story content are copied.

## Content warning

Contains sudden loud sounds, flashing lights, claustrophobic spaces, psychological horror, family tragedy, child peril, character death, stylized violence, and corpses. No gore.
